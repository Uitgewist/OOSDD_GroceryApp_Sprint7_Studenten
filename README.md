# UC20 – Aanbiedingspagina

**Beschrijving:**  
Een pagina waar dagelijks nieuwe aanbiedingen worden getoond. Wanneer een aanbieding geactiveerd is, wordt deze automatisch meegenomen in de prijs van de producten in de winkelwagen.

**Belangrijkste punten:**  
- Toont alleen actieve dagelijkse aanbiedingen.  
- Kortingen worden toegepast zonder de originele productprijs te wijzigen.  
- Prijs in de winkelwagen wordt dynamisch aangepast op basis van de aanbieding.
